## Resumen
OmniRoute es una herramienta de código abierto y gratuita que actúa como un router inteligente para múltiples proveedores de IA, permitiendo usar servicios como Cloud Code, Codex, Gemini y más con un consumo de tokens reducido hasta en un 90%. Al conectar más de 600 proveedores, incluyendo modelos gratuitos como BigPickle, DeepSeek V4 Flash y Nemo, permite un uso ilimitado de tokens mediante el enrutamiento automático entre ellos. El proceso de instalación es sencillo: basta con ejecutar un comando npm, configurar una contraseña y conectar cuentas mediante claves API o cookies. Se pueden crear combinaciones personalizadas de modelos con prioridades definidas, optimizando costos y aprovechando ofertas gratuitas. Además, incluye funciones de compresión de prompts como Caveman, RTK y Headroom, que reducen el uso de tokens a costa de un ligero descenso en calidad del resultado.
