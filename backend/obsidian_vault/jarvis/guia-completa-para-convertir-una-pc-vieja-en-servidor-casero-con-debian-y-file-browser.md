## Resumen
Se explica paso a paso cómo reutilizar una computadora vieja como servidor casero instalando Debian sin entorno gráfico, configurando SSH para administración remota, asignando una IP fija y desplegando File Browser como nube local básica. Se detallan los requisitos necesarios, como una PC que encienda, memoria USB, cable Ethernet y preferentemente un SSD, además de decisiones clave como no instalar escritorio y usar particionado guiado. También se abordan errores comunes: SSH no conecta, File Browser no abre, la IP fija deja sin internet y permisos incorrectos en la carpeta. El servidor está pensado únicamente para usarse dentro de la red local, sin exponerlo a internet.
